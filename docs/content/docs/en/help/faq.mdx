## Is Mikrozia free and open source?

Yes. Mikrozia is released under GPL-3.0 and preserves the copyright and
attribution of its upstream project, [3x-ui](https://github.com/MHSanaei/3x-ui).

## What platform does it run on?

MikroTik **RouterOS Container**, RouterOS `7.25+` with the matching Container
package. CHR x86_64 is the reference environment. Published images are
`linux/amd64`, `linux/arm64/v8`, and `linux/arm/v7`. Mikrozia does not run on a
systemd VPS, from a tarball, on Windows, or as a Docker Compose production
stack.

## SQLite or PostgreSQL?

SQLite is the default and is fine for most deployments; the database lives on the
persistent `/etc/x-ui` mount. External PostgreSQL is optional and configured
through RouterOS `/container/envs` (`XUI_DB_TYPE=postgres` and `XUI_DB_DSN`) —
see the [environment variables](/docs/reference/env-vars) and
[database](/docs/reference/database) references. Mikrozia never installs a
PostgreSQL server inside the container.

## Which client apps work with it?

Any Xray-compatible client — for example v2rayNG, Hiddify, and Clash/Mihomo.
Import a client's share link or QR code, or use a
[subscription](/docs/config/subscription).

## Does Mikrozia manage firewall or NAT?

No. Firewall, NAT, masquerade, port-forwarding, routing policy, address lists,
and access control are user-managed in RouterOS. Mikrozia only documents the
ports it listens on inside the container. See
[Ports & firewall](/docs/reference/ports-firewall).

## Does it issue or renew TLS certificates?

Yes, with the ACME client bundled in the image — and only for domains you own.
HTTP-01 issuance is manual, Cloudflare DNS-01 issuance renews automatically, and
everything is stored on the persistent `/root/cert` mount. You can still import
a certificate you already own and point the panel at it. Mikrozia never creates
or changes a RouterOS firewall, NAT, or port-forwarding rule for you. See
[TLS certificates](/docs/config/ssl-certificates).

## How do I update?

Replace the container image. Pull the new versioned tag from Docker Hub
`majlot/mikrozia`, recreate the container with the same `/etc/x-ui` and
`/root/cert` mounts, and keep the previous image until the new one is verified.
There is no in-container panel, Xray, Geo, or software updater. See
[Update & uninstall](/docs/guide/update-uninstall).

## How is Mikrozia different from 3x-ui?

Mikrozia is built for RouterOS Container from the 3x-ui code base: immutable
images, no systemd, no host-firewall management, no runtime software updates,
and RouterOS-owned network policy. Upstream 3x-ui remains the historical source
and is credited as required by the license.

## Where can I get help?

Start with [Troubleshooting](/docs/help/troubleshooting). When reporting a
problem, include the RouterOS version, the Mikrozia image tag, container status,
and the relevant container log lines — never private keys or passwords.
