**Mikrozia** packages the [3x-ui](https://github.com/MHSanaei/3x-ui) panel and
[Xray-core](https://github.com/XTLS/Xray-core) as a versioned OCI image for
**MikroTik RouterOS Container**, with CHR x86_64 as the reference platform. It
gives you the panel dashboard, inbounds, clients, traffic accounting,
subscriptions, and a REST API — without systemd, host-firewall management, or
runtime software updates.

This site also contains **interactive, in-browser tools** (config generators)
that run entirely on your device — no data ever leaves the page.

## The RouterOS contract

- Mikrozia runs only as a RouterOS Container; it is not a VPS or systemd
  installation.
- The supported update is a new versioned image with the same persistent mounts
  (`/etc/x-ui` and `/root/cert`).
- RouterOS firewall, NAT, port-forwarding, routing, and access-control policy is
  user-managed. Mikrozia never changes it and ships no firewall tooling.
- Certificates are user-managed: obtain and renew them outside the container and
  configure their paths. There is no ACME client or renewal daemon inside.
- Panel, Xray, sidecars, and Geo data are immutable image content. There is no
  runtime software updater.

## Highlights

- **Every major protocol** — VLESS, VMess, Trojan, Shadowsocks, WireGuard,
  AmneziaWG (userspace), TUIC v5, Hysteria2, SOCKS, HTTP, and Dokodemo-door.
- **REALITY & XTLS-Vision** — modern, censorship-resistant transports.
- **Per-client controls** — traffic quotas, expiry dates, IP logging, share
  links, and QR codes.
- **Subscriptions** — VLESS, Clash/Mihomo, and JSON formats.
- **Operations** — multi-node management, Telegram and Discord bots, backups, and a REST API.
