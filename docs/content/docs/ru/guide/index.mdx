**Mikrozia** — это веб-панель для [Xray-core](https://github.com/XTLS/Xray-core),
упакованная как неизменяемый образ контейнера MikroTik RouterOS. Вместо ручного
написания и перезагрузки JSON-конфигурации Xray вы управляете всем — inbound-
подключениями, протоколами, клиентами, сертификатами и подписками — из
браузерной панели.

## Как всё устроено

<Mermaid
  chart={`
flowchart LR
  Admin["Браузер администратора"] -->|порт панели| ROS["Сетевая политика RouterOS (управляет пользователь)"]
  ROS -->|адрес контейнера| Panel["Панель Mikrozia (контейнер)"]
  Panel -->|записывает конфигурацию, перезагружает| Xray["Xray-core (тот же образ)"]
  Panel --- DB[("SQLite или внешний PostgreSQL")]
  Clients["Клиентские приложения"] -->|VLESS / VMess / Trojan / ...| ROS
  Xray -->|проксируемый трафик| Internet["Интернет"]
`}
/>

- **Панель** — уровень управления: хранит конфигурацию в базе данных, отображает
  интерфейс, предоставляет REST API и записывает рабочую конфигурацию Xray.
- **Xray-core** — уровень данных: принимает подключения клиентов на ваших
  **inbound-подключениях** и перенаправляет трафик к месту назначения.
- **Клиентские приложения** (v2rayNG, Clash/Mihomo, Hiddify и другие)
  подключаются по ссылке или подписке, которую панель создаёт для каждого
  клиента.
- **RouterOS** владеет средой выполнения контейнера, сетевым путём и всей
  политикой брандмауэра, NAT и маршрутизации.

## Что вы получаете

- Панель управления **inbound-подключениями** для всех основных протоколов —
  VLESS, VMess, Trojan, Shadowsocks, WireGuard, AmneziaWG (userspace), TUIC v5,
  Hysteria2, SOCKS, HTTP и Dokodemo-door.
- Полноценную поддержку **REALITY** и **XTLS-Vision** для скрытных и быстрых
  транспортов.
- **Для каждого клиента** — квоты трафика, сроки действия, журналирование IP,
  онлайн-статус, ссылки для подключения и QR-коды.
- **Подписки** в форматах VLESS, Clash/Mihomo и JSON.
- Средства эксплуатации: управление **несколькими узлами**, **боты Telegram и
  Discord**, резервные копии и документированный REST API.

## Чем это не является

- Это не Linux VPS и не служба systemd; здесь нет установщика для хоста,
  пакетов дистрибутивов, tarball-архивов, сборки для Windows и производственного
  пути через Docker Compose.
- Это не менеджер брандмауэра, NAT, проброса портов или контроля доступа.
- Это не удостоверяющий центр и не ACME-клиент; сертификаты подключаются по пути.
- Это не самообновляемая система: панель, Xray, sidecar-компоненты и геоданные
  меняются только заменой образа.

## Внутреннее устройство

| Уровень         | Технология |
| --------------- | ---------- |
| Платформа       | Контейнер MikroTik RouterOS (эталон — CHR x86_64) |
| Серверная часть | Go и веб-фреймворк Gin |
| Клиентская часть| TypeScript / React |
| База данных    | SQLite в `/etc/x-ui` (по умолчанию) или внешний PostgreSQL |
| Прокси-движок  | Xray-core (входит в образ) |

База данных SQLite по умолчанию находится в `/etc/x-ui/x-ui.db`, а панель
слушает порт **2053** внутри контейнера. Оба параметра настраиваются — см.
[Первый вход](/docs/guide/first-login) и справочник переменных окружения.

## Для кого это

Mikrozia предназначена для администраторов RouterOS, которым нужна панель Xray
без отказа от контроля RouterOS над сетью. Если вам нужна установка на VPS с
systemd, используйте вышестоящий проект [3x-ui](https://github.com/MHSanaei/3x-ui).
