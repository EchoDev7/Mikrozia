**Mikrozia** упаковывает панель [3x-ui](https://github.com/MHSanaei/3x-ui) и
[Xray-core](https://github.com/XTLS/Xray-core) в версионируемый OCI-образ для
**контейнера MikroTik RouterOS**; эталонная платформа — CHR x86_64. Вы получаете
панель управления, inbound-подключения, клиентов, учёт трафика, подписки и REST
API — без systemd, управления брандмауэром хоста и обновлений ПО во время работы.

На сайте также есть **интерактивные инструменты** (генераторы конфигураций),
которые работают полностью в вашем браузере — данные не покидают страницу.

## Контракт RouterOS

- Mikrozia работает только как контейнер RouterOS; это не установка на VPS и не
  служба systemd.
- Поддерживаемое обновление — новый версионируемый образ с теми же постоянными
  монтированиями (`/etc/x-ui` и `/root/cert`).
- Политика брандмауэра, NAT, проброса портов, маршрутизации и контроля доступа
  RouterOS управляется пользователем. Mikrozia никогда её не меняет и не содержит
  средств работы с брандмауэром.
- Встроенный ACME-клиент выпускает сертификаты через HTTP-01 с ручным продлением
  или Cloudflare DNS-01 с автоматическим продлением. Сертификаты, ключи, данные
  учётной записи и продления сохраняются в `/root/cert`; также поддерживается
  импорт существующей пары.
- Панель, Xray, sidecar-компоненты и геоданные — неизменяемое содержимое образа.
  Обновления ПО во время работы нет.

## Возможности

- **Все основные протоколы** — VLESS, VMess, Trojan, Shadowsocks, WireGuard,
  AmneziaWG (userspace), TUIC v5, Hysteria2, SOCKS, HTTP и Dokodemo-door.
- **REALITY и XTLS-Vision** — современные транспорты, устойчивые к блокировкам.
- **Управление клиентами** — квоты трафика, сроки действия, журналирование IP,
  ссылки для подключения и QR-коды.
- **Подписки** — форматы VLESS, Clash/Mihomo и JSON.
- **Эксплуатация** — управление несколькими узлами, боты Telegram и Discord,
  резервные копии и REST API.
