**Mikrozia** پنل [3x-ui](https://github.com/MHSanaei/3x-ui) و
[Xray-core](https://github.com/XTLS/Xray-core) را به‌صورت یک Image نسخه‌دار OCI
برای **MikroTik RouterOS Container** ارائه می‌کند و CHR x86_64 محیط مرجع آن است.
داشبورد پنل، Inboundها، کلاینت‌ها، حسابداری ترافیک، Subscriptionها و REST API را
بدون systemd، بدون مدیریت Firewall میزبان و بدون به‌روزرسانی نرم‌افزار در زمان
اجرا در اختیار شما می‌گذارد.

این سایت همچنین شامل **ابزارهای تعاملی درون‌مرورگری** (تولیدکننده‌های پیکربندی)
است که کاملاً روی دستگاه شما اجرا می‌شوند — هیچ داده‌ای از صفحه خارج نمی‌شود.

## قرارداد RouterOS

- Mikrozia فقط به‌صورت RouterOS Container اجرا می‌شود؛ نصب VPS یا systemd ندارد.
- به‌روزرسانی پشتیبانی‌شده یعنی Image نسخه‌دار جدید با همان Mountهای پایدار
  (`/etc/x-ui` و `/root/cert`).
- Firewall، NAT، Port Forward، Routing و Access Control در RouterOS بر عهدهٔ کاربر
  است. Mikrozia هرگز آن‌ها را تغییر نمی‌دهد و ابزار Firewall همراه ندارد.
- گواهی‌ها بر عهدهٔ کاربر هستند: آن‌ها را بیرون از کانتینر تهیه و تمدید کنید و
  مسیرشان را معرفی کنید. هیچ کلاینت ACME یا Daemon تمدید داخل کانتینر نیست.
- پنل، Xray، Sidecarها و داده‌های Geo محتوای تغییرناپذیر Image هستند. هیچ
  به‌روزرسان نرم‌افزاری در زمان اجرا وجود ندارد.

## ویژگی‌های شاخص

- **همهٔ پروتکل‌های اصلی** — VLESS، VMess، Trojan، Shadowsocks، WireGuard،
  AmneziaWG (فضای کاربر)، TUIC v5، Hysteria2، SOCKS، HTTP و Dokodemo-door.
- **REALITY و XTLS-Vision** — ترنسپورت‌های مدرن و مقاوم در برابر سانسور.
- **کنترل هر کلاینت** — سهمیهٔ ترافیک، تاریخ انقضا، ثبت IP، لینک اشتراک‌گذاری و
  QR Code.
- **Subscriptionها** — قالب‌های VLESS، Clash/Mihomo و JSON.
- **عملیات** — مدیریت چندنودی، ربات‌های Telegram و Discord، پشتیبان‌گیری و REST API.
