**Mikrozia** یک پنل کنترل تحت وب برای
[Xray-core](https://github.com/XTLS/Xray-core) است که به‌صورت Image تغییرناپذیر
MikroTik RouterOS Container ارائه می‌شود. به‌جای نوشتن و بارگذاری دستی پیکربندی
JSON، همه‌چیز — Inboundها، پروتکل‌ها، کلاینت‌ها، گواهی‌ها و Subscriptionها — را از
داشبورد مرورگر مدیریت می‌کنید.

## اجزا چگونه کنار هم کار می‌کنند

- **پنل** لایهٔ مدیریت است: پیکربندی را در دیتابیس ذخیره می‌کند، داشبورد را
  رندر می‌کند، REST API ارائه می‌دهد و پیکربندی زندهٔ Xray را می‌نویسد.
- **Xray-core** لایهٔ داده است: اتصال کلاینت‌ها را روی **Inboundها** پایان می‌دهد
  و ترافیک را به مقصد هدایت می‌کند.
- **اپلیکیشن‌های کلاینت** (مانند v2rayNG، Clash/Mihomo و Hiddify) با لینک
  اشتراک‌گذاری یا Subscription ساخته‌شده توسط پنل متصل می‌شوند.
- **RouterOS** مالک Runtime کانتینر، مسیر شبکه و همهٔ سیاست‌های Firewall، NAT و
  Routing است.

## چه چیزی در اختیار شما می‌گذارد

- داشبورد **Inboundها** در همهٔ پروتکل‌های اصلی — VLESS، VMess، Trojan،
  Shadowsocks، WireGuard، AmneziaWG (فضای کاربر)، TUIC v5، Hysteria2، SOCKS، HTTP
  و Dokodemo-door.
- پشتیبانی درجه‌یک از **REALITY** و **XTLS-Vision** برای ترنسپورت‌های مخفی و سریع.
- **سهمیهٔ ترافیک**، تاریخ انقضا، ثبت IP، وضعیت آنلاین و لینک اشتراک/QR Code برای
  هر کلاینت.
- **Subscriptionها** در قالب‌های VLESS، Clash/Mihomo و JSON.
- ابزارهای عملیاتی: مدیریت **چندنودی**، **ربات‌های Telegram و Discord**،
  پشتیبان‌گیری و REST API مستند.

## چه چیزی نیست

- VPS لینوکسی یا سرویس systemd نیست؛ نصب‌کنندهٔ میزبان، بستهٔ توزیع، Tarball،
  نسخهٔ Windows یا مسیر تولیدی Docker Compose ندارد.
- مدیر Firewall، NAT، Port Forward یا Access Control نیست.
- کلاینت ACME پیوست‌شده برای HTTP-01 دستی و Cloudflare DNS-01 با تمدید خودکار؛
  گواهی‌ها و وضعیت تمدید زیر `/root/cert` پایدار می‌مانند.
- خودبه‌روزرسان نیست: پنل، Xray، Sidecarها و داده‌های Geo فقط با جایگزینی Image
  تغییر می‌کنند.

## در پشت صحنه

| لایه | فناوری |
| ---- | ------ |
| پلتفرم | MikroTik RouterOS Container (مرجع CHR x86_64) |
| Backend | Go با فریم‌ورک Gin |
| Frontend | TypeScript / React |
| دیتابیس | SQLite روی `/etc/x-ui` (پیش‌فرض) یا PostgreSQL خارجی |
| موتور پروکسی | Xray-core (همراه Image) |

دیتابیس پیش‌فرض SQLite در `/etc/x-ui/x-ui.db` قرار دارد و پنل داخل کانتینر روی
پورت **2053** گوش می‌دهد. هر دو قابل تغییرند — به [نخستین ورود](/docs/guide/first-login)
و مرجع متغیرهای محیطی مراجعه کنید.

## برای چه کسانی است

Mikrozia برای مدیران RouterOS است که پنل Xray می‌خواهند بدون از دست دادن مالکیت
شبکه در RouterOS. اگر نصب VPS با systemd نیاز دارید، از پروژهٔ بالادستی
[3x-ui](https://github.com/MHSanaei/3x-ui) استفاده کنید.
