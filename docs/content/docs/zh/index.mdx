**Mikrozia** 将 [3x-ui](https://github.com/MHSanaei/3x-ui) 面板与
[Xray-core](https://github.com/XTLS/Xray-core) 打包为面向 **MikroTik RouterOS
容器** 的版本化 OCI 镜像，参考平台为 CHR x86_64。你因此获得面板仪表盘、
入站、客户端、流量统计、订阅和 REST API——无需 systemd、主机防火墙管理或运行时
软件更新。

本站还包含完全在你的浏览器中运行的**交互式工具**（配置生成器），数据不会离开页面。

## RouterOS 约定

- Mikrozia 仅作为 RouterOS 容器运行；它不是 VPS 或 systemd 安装。
- 受支持的更新方式是使用新版本镜像，并保留相同的持久化挂载
  （`/etc/x-ui` 与 `/root/cert`）。
- RouterOS 的防火墙、NAT、端口转发、路由和访问控制策略由用户管理。Mikrozia
  从不修改它们，也不内置防火墙工具。
- 证书由用户管理：在容器外获取和续期，并以路径方式配置。容器内没有 ACME
  客户端或续期进程。
- 面板、Xray、sidecar 组件和 Geo 数据都是不可变的镜像内容，没有运行时软件更新器。

## 亮点

- **覆盖主要协议**——VLESS、VMess、Trojan、Shadowsocks、WireGuard、
  AmneziaWG（用户态）、TUIC v5、Hysteria2、SOCKS、HTTP 和 Dokodemo-door。
- **REALITY 与 XTLS-Vision**——现代、抗审查的传输方式。
- **按客户端控制**——流量配额、到期时间、IP 记录、分享链接和二维码。
- **订阅**——VLESS、Clash/Mihomo 与 JSON 格式。
- **运维**——多节点管理、Telegram 与 Discord 机器人、备份以及 REST API。
