## Mikrozia 是否免费且开源？

是的。Mikrozia 以 GPL-3.0 许可发布，并保留其上游项目
[3x-ui](https://github.com/MHSanaei/3x-ui) 的版权与署名。

## 它运行在什么平台上？

MikroTik **RouterOS 容器**，即 RouterOS `7.25+` 及配套的 Container 软件包。
参考环境为 CHR x86_64。发布的镜像包括 `linux/amd64`、`linux/arm64/v8` 和
`linux/arm/v7`。Mikrozia 不能运行在 systemd VPS 上，也不能从 tarball 运行、
在 Windows 上运行，或作为 Docker Compose 生产栈运行。

## 选 SQLite 还是 PostgreSQL？

SQLite 是默认选项，适用于大多数部署；数据库位于持久化挂载 `/etc/x-ui` 上。
外部 PostgreSQL 是可选项，通过 RouterOS `/container/envs` 配置
（`XUI_DB_TYPE=postgres` 和 `XUI_DB_DSN`）——参见
[环境变量](/docs/reference/env-vars)与[数据库](/docs/reference/database)参考。
Mikrozia 从不在容器内安装 PostgreSQL 服务器。

## 哪些客户端应用可以配合使用？

任何兼容 Xray 的客户端——例如 v2rayNG、Hiddify 以及 Clash/Mihomo。
导入客户端的分享链接或 QR 码，或者使用[订阅](/docs/config/subscription)。

## Mikrozia 会管理防火墙或 NAT 吗？

不会。防火墙、NAT、masquerade、端口转发、路由策略、地址列表和访问控制均由用户在
RouterOS 中管理。Mikrozia 只记录它在容器内监听的端口。参见
[端口与防火墙](/docs/reference/ports-firewall)。

## 它会签发或续期 TLS 证书吗？

会，使用镜像内置的 ACME 客户端——且仅限您拥有的域名。HTTP-01 签发为手动操作，
Cloudflare DNS-01 签发自动续期，所有内容都保存在持久化挂载 `/root/cert` 上。
您仍然可以导入自己已有的证书并在面板中配置其路径。Mikrozia 绝不会为您创建或
修改 RouterOS 的防火墙、NAT 或端口转发规则。参见 [TLS 证书](/docs/config/ssl-certificates)。

## 如何更新？

替换容器镜像。从 Docker Hub `echodev7/mikrozia` 拉取新的版本化标签，使用相同的
`/etc/x-ui` 与 `/root/cert` 挂载重新创建容器，并在验证新镜像之前保留旧镜像。
容器内没有面板、Xray、Geo 数据或软件更新器。参见
[更新与卸载](/docs/guide/update-uninstall)。

## Mikrozia 与 3x-ui 有什么区别？

Mikrozia 基于 3x-ui 代码库，专为 RouterOS 容器构建：不可变镜像、无 systemd、
不管理主机防火墙、无运行时软件更新，网络策略由 RouterOS 掌控。上游 3x-ui
仍是历史来源，并按许可证要求注明出处。

## 在哪里可以获得帮助？

请先阅读[故障排查](/docs/help/troubleshooting)。报告问题时，请附上 RouterOS
版本、Mikrozia 镜像标签、容器状态和相关容器日志行——切勿发送私钥或密码。
