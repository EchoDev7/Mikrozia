## 在 RouterOS 设备之间迁移

迁移到另一台 RouterOS 设备就是迁移挂载数据：

<Steps>

<Step>
### 备份旧设备

停止容器，然后复制 `/etc/x-ui` 与 `/root/cert` 挂载的内容。参见
[备份与恢复](/docs/operations/backup-restore)。
</Step>

<Step>
### 在新设备上安装相同的 Mikrozia 标签

按照 [RouterOS 安装路径](/docs/guide/installation)操作，并使用相同的镜像标签，除非你
有意升级。创建相同的持久化挂载。
</Step>

<Step>
### 恢复挂载数据

在启动容器之前，将数据库与证书放到新的持久化挂载上。启动后更新所有与 IP 或域名
相关的面板设置。
</Step>

</Steps>

## 在不同 Mikrozia 版本之间迁移

替换容器镜像是唯一受支持的升级机制。面板会在启动时迁移自己的数据库。请先
[备份](/docs/operations/backup-restore)，使用新的版本化标签和相同的
`/etc/x-ui`、`/root/cert` 挂载重新创建容器，并在验证新镜像之前保留旧镜像。切勿从
容器内部重写镜像 RootFS。

## 从 x-ui 迁移

将旧版 x-ui 面板的数据库直接导入 Mikrozia **不受支持**——两者的数据库结构不同。请
全新安装 Mikrozia 并重新创建入站/客户端，同时从旧面板逐一导出分享链接。

<Callout type="warn">
  在任何迁移之前都要先做好备份，并在确认新服务器正常工作之前保持旧服务器继续运行。
</Callout>
