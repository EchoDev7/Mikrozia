Mikrozia 从环境变量中读取运行时配置。在 RouterOS Container 上，请通过 `/container/envs` 定义变量并将其 `envlist` 挂载到容器；本地开发使用 Docker 时，可在 `docker-compose.yml` 或 `docker run -e` 中设置。更改环境变量后，请使用相同的持久挂载（`/etc/x-ui` 与 `/root/cert`）重建容器。

## RouterOS API 状态与遥测

仪表板可以通过容器与路由器之间的内部网络，仅在 TCP/8728 上执行只读的原生
RouterOS API 查询。这些变量为可选项：要么全部设置，要么全部不设置；部分
配置无效。Mikrozia 不会启用 API 服务、创建用户或更改路由器设置。

| 变量 | 默认值 | 说明 |
| --- | --- | --- |
| `MIKROZIA_ROUTEROS_API_HOST` | — | RouterOS API 的私有字面 IPv4/IPv6 地址（不接受主机名、zone、回环或链路本地地址）。 |
| `MIKROZIA_ROUTEROS_API_USERNAME` | — | 专用只读 RouterOS API 帐户名（仅需 `read,api` 权限）。 |
| `MIKROZIA_ROUTEROS_API_PASSWORD` | — | RouterOS API 帐户密码。 |

请使用占位值，例如 `172.16.10.1`、`<READ_ONLY_API_USER>` 和
`<SET_A_SECRET_VALUE>`。密码仅在探测时保留于进程内存，不写入数据库，也不会由
面板 API 返回。RouterOS `/container/envs` 对路由器管理员可见，并非秘密存储。
该集成每 15 秒轮询一次 `/system/resource/print`（`uptime`、`cpu-load`、
`cpu-count`、`cpu-frequency`、`total-memory`、`free-memory`），超时为 4 秒，
陈旧阈值为 30 秒；RouterOS 容器日志读取与 VETH 遥测仍为延后事项。

## 管理员凭据

容器环境是面板管理员账号的**权威来源**。既没有固定的 `admin/admin` 默认值，也没有生成一次的首次登录密码。

| 变量                     | 默认值 | 说明                                     |
| ------------------------ | ------ | ---------------------------------------- |
| `MIKROZIA_ADMIN_USERNAME` | —      | 管理员用户名。必须与密码一起设置。       |
| `MIKROZIA_ADMIN_PASSWORD` | —      | 管理员密码。必须与用户名一起设置。       |

面板每次启动都会把已保存的管理员账号与这两个值对齐：用户名和密码会被更新，密码变更后使用旧密码签发的会话随即失效。已有账号绝不会被静默删除或重置。

| 情况                                                  | 行为                                                          |
| ----------------------------------------------------- | ------------------------------------------------------------- |
| 两个值都已设置                                        | 环境拥有该账号；每次启动都会对齐已保存的账号。                |
| 只设置了其中一个                                      | 面板拒绝启动，并指出缺少的值。任何内容都不会被更改。        |
| 两者都未设置，但已存在账号                            | 已保存的账号原样保留，面板在日志中说明该账号由别处管理。    |
| 两者都未设置，且没有账号                              | 面板拒绝启动，并要求提供这两个值。                          |
| 两者都未设置，已保存账号仍是旧的 `admin` / `admin`   | 面板拒绝启动，并保留已保存的账号。                          |

当环境拥有该账号时，面板的**安全**标签页会显示提示而不是密码表单，面板内修改密码也会以明确的信息被拒绝 —— 环境会在下次启动时覆盖它。

<Callout type="warn">
  **RouterOS 的容器环境是配置存储，而不是机密存储。** `/container/envs` 中的每个
  值对任何能读取或导出路由器配置的人都可见。请为管理员选择强密码，并保护路由器
  自身的访问权限与备份。Mikrozia 绝不会把这些值打印到日志、绝不通过 API 返回，
  也绝不写入镜像。
</Callout>

## 数据库

| Variable                 | Default     | Description                                                          |
| ------------------------ | ----------- | -------------------------------------------------------------------- |
| `XUI_DB_TYPE`            | `sqlite`    | 后端：`sqlite`，或 `postgres`（也接受 `postgresql` / `pg`）。       |
| `XUI_DB_FOLDER`          | `/etc/x-ui` | SQLite 数据库文件（`x-ui.db`）所在的文件夹。                         |
| `XUI_DB_DSN`             | —           | PostgreSQL URI（`postgres://` / `postgresql://`）或键值对 DSN（高级选项；当 `XUI_DB_TYPE=postgres` 时使用）。TLS 证书请置于 `/root/cert`（推荐 `sslmode=verify-full`）；不支持 `PGPASSWORD`。 |
| `XUI_DB_MAX_OPEN_CONNS`  | —           | PostgreSQL 连接池中的最大打开连接数。                               |
| `XUI_DB_MAX_IDLE_CONNS`  | —           | PostgreSQL 连接池中的最大空闲连接数。                               |

默认的 SQLite 数据库路径为 `/etc/x-ui/x-ui.db`。有关 SQLite ↔ PostgreSQL 的
细节，参见 [数据库](/docs/reference/database)。

## 节点令牌加密

节点 API bearer 令牌以及已保存的 PIA 令牌默认以明文存储。静态加密需显式开启，
且采取失败即拒绝的策略：只要模式不是 `off`，面板在无法加载密钥时就拒绝启动。

| Variable                  | Default                         | Description                                                                                                                                                            |
| ------------------------- | ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `NODE_TOKEN_ENCRYPTION`   | `off`                           | `off`、`migration`（读取时接受明文或密文，写入一律加密）或 `required`（写入相同，但缺少密钥时启动失败）。注意此处没有 `XUI_` 前缀。                                     |
| `XUI_NODE_TOKEN_KEY_FILE` | `/etc/x-ui/node_token_key.json` | JSON 密钥环，权限须为 `0600` 或更严格。优先加载。                                                                                |
| `XUI_NODE_TOKEN_KEY`      | —                               | 单个 base64 编码的 32 字节密钥，仅在密钥文件加载失败时读取。其密钥 ID 固定为 `env`，因此无法轮换。                                                                      |

密钥文件同时记录活动密钥和所有仍需用于解密的旧密钥：

```json
{ "active": "k1", "keys": { "k1": "<base64 32-byte key>" } }
```

使用 `openssl rand -base64 32` 生成密钥；密钥绝不接受通过命令行参数传入。启用某个
模式后，用活动密钥重新加密数据库中已有的记录：

```bash
x-ui encrypt-tokens
```

该命令处理节点记录；PIA 令牌会在下次读取时重新加密。轮换密钥时，将新密钥加入
`keys`，把 `active` 指向它，保留旧密钥用于解密，然后再次运行 `x-ui encrypt-tokens`。

## 内存与性能分析

面板通过 `GOGC` 和定期释放来保持低内存占用。这些是高级调节项——除非你正在
为受限主机做调优，否则请保持不设置。

| Variable                      | Default | Description                                                       |
| ----------------------------- | ------- | ----------------------------------------------------------------- |
| `XUI_GOGC`                    | —       | Go GC 目标百分比；值越低 = 占用 RAM 越少，CPU 略增。              |
| `XUI_MEMORY_RELEASE_INTERVAL` | —       | 两次 `FreeOSMemory` 调用之间的分钟数；`0` 表示禁用。              |
| `XUI_MEMORY_LIMIT`            | —       | Go 软内存限制，单位 **MiB**。                                     |
| `GOMEMLIMIT`                  | —       | Go 语法的软限制（例如 `400MiB`）；优先级高于上一项。              |
| `XUI_PPROF`                   | `false` | 在 `127.0.0.1:6060` 上暴露 pprof 性能分析。                       |

## 隧道健康监测器

可选的看门狗：它探测一个 URL（可选择**经由**本地 Xray 入站进行），并在反复
失败后重启 Xray。重启会断开所有已连接的客户端，因此请审慎启用。

| Variable                      | Default                                      | Description                                                       |
| ----------------------------- | -------------------------------------------- | ----------------------------------------------------------------- |
| `XUI_TUNNEL_HEALTH_MONITOR`   | `false`                                      | 启用监测器。                                                      |
| `XUI_TUNNEL_HEALTH_PROXY`     | —                                            | 用于发送探测的代理，例如 `socks5://127.0.0.1:1080`。留空 = 仅检查主机连通性。 |
| `XUI_TUNNEL_HEALTH_URL`       | `https://www.cloudflare.com/cdn-cgi/trace`   | 要探测的 URL。                                                    |
| `XUI_TUNNEL_HEALTH_INTERVAL`  | `30s`                                        | 探测之间的间隔。                                                 |
| `XUI_TUNNEL_HEALTH_TIMEOUT`   | `10s`                                        | 单次探测的超时时间。                                            |
| `XUI_TUNNEL_HEALTH_FAILURES`  | `3`                                          | 触发重启前的连续失败次数。                                      |
| `XUI_TUNNEL_HEALTH_COOLDOWN`  | `5m`                                         | 两次重启之间的最小延迟。                                        |

## ACME

### `MIKROZIA_CF_API_TOKEN`

用于 **DNS-01** 证书签发与自动续期的最小权限 Cloudflare API 令牌。该变量是可选
的：首选隐藏交互输入（`x-ui` → `14 — TLS Certificates` → `4` 或
`x-ui acme cloudflare setup --domain <domain>`），因为 RouterOS Environment
中的值在路由器配置里可见。仅对明确的非交互场景支持单行 `--stdin`；普通继承的
标准输入会被拒绝。

该令牌绝不会被写入日志，绝不会通过 API 以明文返回，绝不会嵌入生成的配置，也
绝不会被写入不可变的镜像根文件系统。它以 `0600` 权限保存在持久证书挂载目录，
因此镜像替换和回滚后依然保留。

<Callout type="warn">
  RouterOS Environment 中的令牌对任何能读取或导出路由器配置的人都可见。请优先使用
  `x-ui acme cloudflare setup --domain <domain>` 的隐藏交互输入，把令牌限制在单个 Zone
  （`Zone → DNS → Edit` 与 `Zone → Zone → Read`），并在他人接触过路由器后及时
  轮换。
</Callout>
