反向代理让你能够在一个简洁的域名上提供面板和订阅服务，并自动启用 HTTPS，同时将真实端口隐藏在 80/443 端口之后。代理运行在容器之外，通常位于另一台主机。面板本身也可以使用你挂载到 `/root/cert` 的证书直接终结 TLS——参见
[TLS 证书](/docs/config/ssl-certificates)。

代理必须通过容器地址（初学者布局中为 `172.16.10.2:2053`）访问面板。建立这条路径——包括任何端口转发或路由——属于由你配置的 RouterOS 策略，Mikrozia 不会创建它。参见
[端口与防火墙](/docs/reference/ports-firewall)。

## Nginx + 证书

使用 Nginx 时，请在代理主机上（Mikrozia 容器之外）通过 `certbot`（或 `acme.sh`）
获取证书，并在 server 块中引用它：

```bash title="certbot"
certbot certonly --nginx -d panel.example.com
```

安装证书后请重新加载 Nginx，并设置自动续期（`certbot renew` 默认通过定时器运行）。

## Caddy

Caddy 会为你获取并续期证书——只需让 Caddyfile 指向面板，它便能正常工作：

```text title="Caddyfile"
panel.example.com {
    reverse_proxy 172.16.10.2:2053 {
        header_up X-Real-IP {remote_host}
    }
}
```

## 小贴士

- 即使在代理之后，也请保留面板的 **Web 基础路径**；这是纵深防御。
- 如果你在代理处终结 TLS，可能需要在面板上设置 `XUI_SKIP_HSTS=true`——参见[环境变量参考](/docs/reference/env-vars)。
- 也请代理[订阅](/docs/config/subscription)服务器，使其内容通过 HTTPS 提供。
