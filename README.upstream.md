# 3X-UI (بالادست — فقط سابقه)

**3X-UI** یک پنل کنترل وب متن‌باز برای مدیریت سرورهای [Xray-core](https://github.com/XTLS/Xray-core) است. این پروژه فورک بهبودیافتهٔ X-UI است و پشتیبانی گسترده‌تر از پروتکل‌ها، پایداری بهتر و حسابداری ترافیک هر کلاینت را اضافه می‌کند.

این متن برای حفظ سابقه، تقدیر و رعایت مجوز GPL-3.0 نگه داشته شده است. دستورهای نصب و استقرار موجود در نسخه‌های پیشین این فایل (اسکریپت نصب، سرویس systemd، Docker Compose، Fail2ban و به‌روزرسانی درجا) برای Mikrozia **پشتیبانی نمی‌شوند** و نباید دنبال شوند.
